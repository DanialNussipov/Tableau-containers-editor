# Tableau Containers Editor

Инструмент для парсинга, анализа и программного изменения структуры макета (layout containers), отступов (padding/margin), скругления углов (`corner-radius`) и цветов рамок (`border-color`) в файлах Tableau `.twb`. Проект включает в себя мощный бэкенд на FastAPI и удобный веб-интерфейс.

## Возможности
- **Парсинг XML `.twb` файлов:** Извлечение иерархической структуры дашбордов и вложенных зон.
- **Текстовый отчет:** Генерация древовидного представления контейнеров.
- **Пакетное изменение стилей:** Настройка внутренних/внешних отступов, радиуса скругления углов и цвета границ для выбранных зон.
- **Веб-интерфейс:** Современная панель управления для работы с файлами «в один клик».

## Запуск через Docker (Рекомендуется)

Для запуска приложения вам понадобится установленный [Docker](https://www.docker.com/).

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/DanialNussipov/Tableau-containers-editor.git
   cd Tableau-containers-editor
2. Соберите и запустите контейнер с помощью Docker Compose:
    ```bash
    docker-compose up --build
3. Откройте в браузере http://localhost:8000

## Локальный запуск
1. Устновите зависимости:
    ```bash
    pip install -r requirements.txt
2. Запустите сервер разработки:
    ```bash
    python -m uvicorn src.main:app --reload
3. Откройте в браузере http://localhost:8000
